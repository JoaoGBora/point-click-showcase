# Point Click — Gestão Financeira para PMEs

> 🔒 Código privado. Esta página descreve o produto e a arquitetura.

## Problema
Pequenas e médias empresas costumam controlar o financeiro em planilhas soltas, sem DRE, sem projeção de caixa e sem saber quais clientes dão lucro.

## Solução
Aplicação web de gestão financeira com os módulos:
- **Bancos** e **Recebimentos**
- **Fluxo de caixa** realizado e **projetado**
- **DRE** (Demonstrativo de Resultado)
- **Rentabilidade por cliente**
- **Dashboard** gerencial

## Tecnologias
React · TypeScript · tRPC · Drizzle ORM · MySQL

## Roadmap
Evoluir para **SaaS**, com várias empresas na mesma plataforma (multi-tenant).
